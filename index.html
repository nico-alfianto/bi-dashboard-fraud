How This Dashboard Works

Simulated real-time BI feed. Every 2 seconds the system ingests 5–35 new transactions, scores them, and updates all 6 charts. When fraud is detected, an alert appears and a sound plays.

What recruiters should see: You can build a monitoring dashboard, handle live data updates with Chart.js, calculate KPIs on the fly, and design alerts for operational teams — not just static charts.
